# 06 · Alpha 工厂：自己找 alpha，结果反哺下一轮

> 目标：用 Jev/Laya 做一个成熟的量化研究系统，而不是 demo。系统要能自己**发现 alpha**，并用真实结果**反哺迭代**，同时防止最常见的失败方式：在历史数据上试得越多，就越容易"碰巧"找到好看的东西。

## 1. 数据层（point-in-time）

| 内容 | 来源 | 处理 |
|---|---|---|
| 成分股 | fja05680/sp500（MIT），1996 年起每次调整后的完整名单 | 每个交易日只用**当天真实在指数里**的股票；识别出 26 组改名（FB→META 等），其中 2 组误判经 SEC 曾用名核实后剔除 |
| 价格 | Yahoo 日线（已复权），2013–2026，629 只 | 2013 年以来的成分股里有 169 只已退市或被收购、拿不到价格；能覆盖的"成分股 × 交易日"占 **87.6%**（2013 年约 73%，2024 年起约 97%） |
| 财务 | SEC XBRL company facts，608 家公司，约 40 万条 | 每期**只取第一次公布的值**，不用事后修订值；公布的第二天才可见；市值用公司申报的流通市值乘以之后的价格变化（剔除了 3 家申报数值明显错误的公司） |
| 新闻 | SEC 8-K 财报公告（事项 2.02），2016–2026 | 精确到秒的受理时间；每条公告只放在它第一个可交易开盘日 |

重建的市值加权基准和 SPY 对比：相关性 **0.996**，跟踪误差 **1.4%/年**。说明这套数据层可信。

## 2. 工厂

```
候选来源                          准入关卡（事先定死）                         组合与交易
 · 教科书种子（事先写好）           开发期 2014–2020：t ≥ 家族门槛               每周：每个 alpha 按"截至当时已实现"的
 · 随机搜索（语法生成）      →       验证期 2021–2023：同向、t ≥ 1.65、   →      近三年信息比率加权；转负自动归零
 · Claude 读台账后提出假设            扣成本后多空仍赚钱                          → 激进组合：前 50 等权
 · Claude 出题 + Laya 作答           与库内 alpha 相关性 < 0.7                    → 指数增强：市值权重 × (1 + 0.5 z)
          ▲                                                                          │
          └──────────── 研究台账（每个试过的想法、结果和原因） ◀──────────────────────┘
```

**alpha 表达式语言**：由白名单函数构成，比如 `-pct(close, 5)`、`ts_sum(gap, 63)`、`rank(x) * rank(y)`。用 `ast` 解析，只允许白名单里的输入、函数和时间窗口，所以 Claude 或随机搜索写出的东西不可能执行任意代码。复杂度上限为 18 个节点、深度 8。

**开发期门槛**（按"试了多少次"付代价）：

| 来源 | t 值门槛 |
|---|---|
| 教科书种子 | 2.0 |
| Claude 提出 / Laya 提问 | 2.5 |
| 随机搜索 | Bonferroni 校正，随累计试验次数上升（目前约 3.9） |

**三个反哺回路**
1. **研究台账 → Claude**：每一轮 Claude 都先读台账（哪些入库、哪些被拒、为什么），再提新假设。
2. **已实现结果 → 组合权重**：交易时每周重新估计每个 alpha 最近三年的表现，只用已经实现的收益。失效的 alpha 权重自动降到 0。有单元测试专门验证"把未来的收益反转，当天的权重不变"。
3. **错例 → Claude → Laya 的新问题**：把 Laya 的判断和市场反应严重不一致的公告交给 Claude 分析，转化成新的类型化问题。Laya 先在 3,000 条样本上快速筛选，有预测力的再在全部公告上跑，产出的新因子走同样的关卡。

**Laya 的"快"用在哪里**：一个新问题在 2.7 万条公告上跑一遍，Laya 在本地只需要二十几分钟，零成本；交给 Claude 要上百美元。所以大规模试验"该问什么问题"只有 Laya 做得起。

## 3. A 阶段结果：价格 + 财务数据（2026-09-22）

一共试了 **633 个候选**：19 个教科书因子、570 个随机公式、45 个 Claude 假设（Claude 花费 0.34 美元）。**没有一个通过验证。**

开发期表现最好的候选，到验证期全部失效：

| 候选 | 来源 | 开发期 t | 验证期 t |
|---|---|---|---|
| `-(rank(ts_std(close, 42)) * rank(ts_mean(open, 63)))` | 随机 | 3.04 | 0.64 |
| `rank(pct(close, 42)) * rank(asset_growth)` | 随机 | 2.75 | −0.48 |
| 账面市值比（按开发期方向取反） | 种子 | 2.74 | −0.12 |
| 低资产增长（按开发期方向取反） | 种子 | 2.62 | −0.22 |
| `rank(gp_prof) * rank(-(ts_sum(ret, 5)))` | Claude | 2.57 | −0.82 |

**这说明什么**：在标普 500 这个全世界研究最多的股票池里，只用价格和财务数据做周频选股，找不到能在"没参与筛选的时间段"里站得住的信号。如果没有验证期这一关，上面这些都会被当成"发现"，拿去实盘就会亏钱。**关卡拦下它们，恰恰是系统在正常工作。**
